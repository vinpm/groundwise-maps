# Groundwise maps

Offline packs for the Groundwise app. Map packs (release map-packs): base maps, places, road data for
directions, terrain and flood zones, by US state (and Karnataka, India). Reference packs (release
content-packs): medicine labels, self-care pages and herb facts, from public-domain and openly licensed sources. The app downloads them from the releases here when you switch
its internet on for a download; every pack is signed and checked by the app before it is added.

No app code lives here. See NOTICES.md for the data sources and their licences.
